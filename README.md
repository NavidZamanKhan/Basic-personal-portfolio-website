# My First Portfolio Website🌐

Welcome to **My First Portfolio Website**! This project marks my first big step into the world of web development, where I explored the basics of building a web application as a backend Python developer. I’m excited to share what I’ve learned and the skills I’ve showcased here!

## About the Project

This portfolio website is a simple but important milestone in my web development journey. It’s a place where I can present my background, skills, and projects in a clean, functional way. 🚀

While it's basic, it helped me dive into building a full-stack application using:

- **Flask** for the backend
- **HTML**, **CSS**, and **JavaScript** for the frontend

It’s a great learning experience where I got hands-on with core web development concepts, from routing in Flask to styling with CSS and adding dynamic behavior with JavaScript.

## Features ✨

- **Personal Information**: A section dedicated to who I am and what I do.
- **Skills & Project Highlights**: Showcasing the technical skills I’ve developed and the key projects I’ve worked on.
- **Contact Form**: A basic contact form with simple form handling, ready for future improvements!

## Tech Stack 🛠️

- **Backend**: Flask (Python)
- **Frontend**: HTML, CSS, JavaScript
- **Other**: Basic form handling and web structure
